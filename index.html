Como usar este site

  • Cada documento traz a situação (vigente, assinado, enviado, em estudo ou referência), a data e o link para baixar o PDF.
  • Em “Verificar integridade”, o código SHA-256 permite conferir se o arquivo baixado é idêntico ao publicado.
  • Este site é um meio de consulta: em caso de divergência, prevalece o documento oficial assinado.
